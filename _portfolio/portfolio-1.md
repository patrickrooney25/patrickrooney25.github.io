## Project Overview

This project involved the design and implementation of a standalone smart locker system using an ATmega328p microcontroller. The system integrates a servo motor locking mechanism, a keypad-based user interface, and a regulated power supply to provide secure and reliable access control.

Key features of the system include encrypted password storage, password update logic, low-power operating modes, motor blockage detection, low-battery monitoring and alerts, an audible buzzer interface, and MOSFET-based power switching to improve battery efficiency. The project emphasized reliability, security, and embedded-system best practices.
